# Barcode-To-Excel

Excel export of the [Emby Direct](https://github.com/oeaas12-cyber/emby-nuvio-addon) Nuvio/Stremio addon.

**Download:** [emby-direct-project.xlsx](https://github.com/oeaas12-cyber/Barcode-To-Excel/raw/main/emby-direct-project.xlsx)

## Sheets

| Sheet | Contents |
|---|---|
| Summary | Project name, version, dependencies, start command, configure page, source commit, and line counts per file |
| Endpoints | Every server route and what it does |
| addon.js, configure.html, package.json, README.md, .gitignore | The source of each file, line by line |
